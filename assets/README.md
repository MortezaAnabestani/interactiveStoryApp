# 📁 راهنمای Assets

این پوشه شامل تمام تصاویر، موسیقی و افکت‌های صوتی اپلیکیشن است.

## 📂 ساختار پوشه‌ها

```
assets/
├── images/
│   ├── backgrounds/     # تصاویر پس‌زمینه صحنه‌ها
│   ├── characters/      # تصاویر شخصیت‌ها
│   └── ui/             # لوگو، آیکون و المان‌های UI
├── audio/
│   ├── music/          # موسیقی پس‌زمینه
│   └── sfx/            # افکت‌های صوتی
```

## 🖼️ تصاویر

### تصاویر پس‌زمینه (backgrounds/)

فرمت: **JPG یا PNG**
سایز پیشنهادی: **1080x1920** (Full HD عمودی)

فایل‌های مورد نیاز:
- `start.jpg` - پس‌زمینه صحنه شروع داستان
- `battle.jpg` - پس‌زمینه صحنه‌های نبرد
- `palace.jpg` - پس‌زمینه قصر و دربار
- `desert.jpg` - پس‌زمینه صحرا
- `reunion.jpg` - پس‌زمینه صحنه دیدار

### تصاویر شخصیت‌ها (characters/)

فرمت: **PNG با پس‌زمینه شفاف**
سایز پیشنهادی: **600x1200** (تمام قد) یا **400x600** (نیم‌تنه)

فایل‌های مورد نیاز:
- `rostam.png` - تصویر رستم
- `sohrab.png` - تصویر سهراب
- `tahmineh.png` - تصویر تهمینه
- `kavoos.png` - تصویر کاووس

### المان‌های UI (ui/)

فرمت: **PNG**
- `logo.png` - لوگوی اپلیکیشن (800x400)
- `icon.png` - آیکون اپلیکیشن (512x512)

## 🎵 موسیقی (music/)

فرمت: **MP3**
کیفیت پیشنهادی: **128-192 kbps**

فایل‌های مورد نیاز:
- `menu.mp3` - موسیقی منوی اصلی (حدود 2-3 دقیقه، looping)
- `story.mp3` - موسیقی پس‌زمینه داستان (آرام و تامل‌برانگیز)
- `battle.mp3` - موسیقی صحنه‌های نبرد (حماسی و پرانرژی)
- `ending_good.mp3` - موسیقی پایان خوش (امیدوارکننده)
- `ending_bad.mp3` - موسیقی پایان تلخ (غم‌انگیز)

## 🔊 افکت‌های صوتی (sfx/)

فرمت: **MP3 یا WAV**
مدت زمان: **کوتاه (0.5-2 ثانیه)**

فایل‌های مورد نیاز:
- `click.mp3` - صدای کلیک روی دکمه
- `transition.mp3` - صدای انتقال بین صفحات
- `choice.mp3` - صدای انتخاب یک گزینه
- `success.mp3` - صدای موفقیت/پایان خوش
- `fail.mp3` - صدای شکست/پایان بد

## 📥 نحوه اضافه کردن فایل‌ها

### مرحله ۱: کپی فایل‌ها
فایل‌های خود را در پوشه‌های مناسب کپی کنید.

### مرحله ۲: نام‌گذاری دقیق
مطمئن شوید نام فایل‌ها **دقیقاً** مطابق لیست بالا باشد.

### مرحله ۳: تست
اپلیکیشن را مجدداً اجرا کنید تا تصاویر و صداها بارگذاری شوند.

## ⚠️ نکات مهم

1. **حجم فایل‌ها**: سعی کنید تصاویر و موسیقی‌ها را فشرده کنید تا حجم اپ زیاد نشه
2. **کیفیت**: تصاویر باید HD باشند اما نه خیلی سنگین
3. **حق کپی**: فقط از منابع رایگان یا دارای مجوز استفاده کنید
4. **فرمت**: حتماً از فرمت‌های پیشنهادی استفاده کنید
5. **نام‌گذاری**: نام فایل‌ها باید دقیقاً مطابق لیست باشد

## 🔄 Placeholder ها

اگر فایلی ندارید، نگران نباشید! اپلیکیشن از placeholder های آنلاین استفاده می‌کند تا زمانی که فایل واقعی را اضافه کنید.

## 📝 مثال استفاده در کد

```typescript
import { images } from '../assets/images';
import { soundManager } from '../assets/sounds';

// استفاده از تصویر
<Image source={images.backgrounds.battle} />

// پخش موسیقی
await soundManager.playMusic('battle');

// پخش افکت صوتی
await soundManager.playSfx('click');
```

---

**نکته**: بعد از اضافه کردن فایل‌های جدید، اپلیکیشن را restart کنید تا assets بارگذاری شوند.
