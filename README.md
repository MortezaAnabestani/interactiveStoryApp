# رستم و سهراب - داستان تعاملی 📱

یک اپلیکیشن موبایل داستان تعاملی فارسی بر اساس حماسه رستم و سهراب از شاهنامه فردوسی.

## ویژگی‌ها ✨

- 📖 داستان کامل تعاملی با مسیرهای مختلف
- 🎭 چندین پایان متفاوت (خوش، تلخ، خنثی)
- 💾 ذخیره خودکار پیشرفت
- 🎨 رابط کاربری زیبا با پشتیبانی کامل RTL
- 🔄 امکان شروع دوباره داستان
- 📊 نمایش پیشرفت بازی

## پیش‌نیازها 📋

قبل از شروع، مطمئن شوید که موارد زیر را نصب کرده‌اید:

- [Node.js](https://nodejs.org/) (نسخه 16 یا بالاتر)
- [npm](https://www.npmjs.com/) یا [yarn](https://yarnpkg.com/)
- [Expo Go](https://expo.dev/client) روی گوشی موبایل خود

## نصب و راه‌اندازی 🚀

### مرحله ۱: نصب وابستگی‌ها

```bash
npm install
```

یا اگر از yarn استفاده می‌کنید:

```bash
yarn install
```

### مرحله ۲: اجرای برنامه

```bash
npm start
```

یا:

```bash
npx expo start
```

### مرحله ۳: اجرا روی موبایل

پس از اجرای دستور بالا، یک QR کد نمایش داده می‌شود.

**روی اندروید:**
1. اپلیکیشن Expo Go را باز کنید
2. روی "Scan QR code" کلیک کنید
3. QR کد را اسکن کنید

**روی iOS:**
1. اپلیکیشن دوربین را باز کنید
2. QR کد را اسکن کنید
3. روی نوتیفیکیشن Expo کلیک کنید

## دستورات مفید 💻

```bash
# اجرا در حالت توسعه
npm start

# اجرا روی اندروید (با شبیه‌ساز)
npm run android

# اجرا روی iOS (فقط روی macOS)
npm run ios

# اجرا روی وب
npm run web
```

## نحوه بازی 🎮

1. داستان با معرفی رستم و تهمینه شروع می‌شود
2. در هر مرحله، شما انتخاب‌هایی دارید که مسیر داستان را تعیین می‌کنند
3. انتخاب‌های شما می‌توانند منجر به پایان‌های مختلف شوند:
   - 🌟 **پایان خوش**: رستم و سهراب یکدیگر را می‌یابند و در کنار هم می‌مانند
   - 💔 **پایان تلخ**: تکرار تراژدی کلاسیک شاهنامه
   - ✨ **پایان خنثی**: مسیرهای میانه

4. پیشرفت شما به صورت خودکار ذخیره می‌شود
5. می‌توانید هر زمان داستان را از نو شروع کنید
